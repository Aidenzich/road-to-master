# H3 加速 LoRA：相對無 LoRA 的生成耗時統計

統計日期：2026-09-17。

## 結果摘要

在相同生成模式、解析度及片長的歷史成功紀錄中，相對無 LoRA 的 30 步基準，TaoMate 3-step 的耗時中位數約縮短至 **1/3.4～1/4.0**，節省約 **70～75%** 時間；Turbo 8-step 約縮短至 **1/1.4～1/1.7**，節省約 **30～42%** 時間。

這是不同歷史任務的描述性統計，不是同一提示詞與 seed 的配對實驗，也沒有證明畫質相等。數字描述「加速 LoRA＋少步數」這套設定的耗時差異，不能歸因為固定步數下單純載入 LoRA 的收益。

## 統計條件

- 硬體：所選 20 筆紀錄均記錄 NVIDIA GeForce RTX 5090。
- 模式：H3 T2VA，文字生成影片，無參考圖片；每次一個候選。
- 片長：輸出影片 8 秒；依解析度分組。
- 基準：30 步，實際執行圖中沒有載入 LoRA。
- 加速組：實際執行圖確認載入 TaoMate 3-step 或 Turbo 8-step 加速 LoRA。部分任務另疊加其他 LoRA，未將這項變因控制為一致。
- 僅納入成功紀錄；失敗、取消與其他生成模式不併入本表。
- 耗時：執行開始至成品保存，包含模型載入、採樣、解碼及保存，不含執行前排隊與上傳。事後補回事件的觀測時間不能作為執行起點，必要時改用即時執行觀測事件。

## 中位耗時與加速倍率

| 解析度／片長 | 無 LoRA，30 步 | TaoMate，3 步 | Turbo，8 步 |
|---|---:|---:|---:|
| 512×512／8 秒 | 338.2 秒（n=1） | 83.8 秒（n=7） | 196.2 秒（n=3） |
| 736×736／8 秒 | 573.4 秒（n=3） | 168.9 秒（n=3） | 399.7 秒（n=3） |

| 解析度 | TaoMate 加速倍率 | TaoMate 節省時間 | Turbo 加速倍率 | Turbo 節省時間 |
|---|---:|---:|---:|---:|
| 512×512 | 4.03× | 75.2% | 1.72× | 42.0% |
| 736×736 | 3.39× | 70.5% | 1.43× | 30.3% |

計算方式：

- 加速倍率＝基準組耗時中位數 ÷ 加速組耗時中位數。
- 節省時間＝1 − 加速組耗時中位數 ÷ 基準組耗時中位數。
- 使用未四捨五入的中位數計算，再將結果四捨五入顯示。

## 解讀與限制

加速 LoRA 的用途，是讓模型用較少步數仍能生成可用結果。模型載入、編解碼與保存不會隨步數同比縮短，因此 30 步降到 3 步不等於整體快 10 倍。

這些紀錄沒有固定提示詞、seed、冷熱啟動、其他 LoRA 或 GPU 當時負載；512×512 的無 LoRA 基準更只有一筆。不能將倍率視為普遍保證、品質等價證明或因果估計，也不能直接套用到圖生影片、參考影片生成或遮罩修補。
